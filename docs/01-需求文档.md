# 社区团购平台 - 需求文档

## 1. 项目简介
面向社区/园区的团购平台。用户下单购买生鲜日用品，到指定自提点取货；
团长（自提点负责人）管理本团商品与订单；管理员管理全平台。

## 2. 角色与权限

| 角色 | 权限 |
|---|---|
| 普通用户 user | 浏览商品、加购、下单、支付、查订单、评价（可带视频） |
| 团长 leader | 用户全部权限 + 管理本团商品/库存、查看本团订单、发货 |
| 管理员 admin | 全平台商品/分类/用户/订单/团长管理、数据看板 |

## 3. 功能清单

### 3.1 用户端
- 注册 / 登录
- 首页：分类导航、商品列表、搜索、分页
- 商品详情：图片轮播、主图视频播放、库存、加入购物车
- 购物车：增删改、选中、合计
- 下单：选社区自提点、备注、提交
- 支付（模拟）
- 我的订单：按状态筛选、取消、确认收货
- 评价：评分 + 文字 + 图片/视频

### 3.2 团长端
- 本团商品管理（上下架、改库存/价格）
- 本团订单列表、发货
- 本团数据：今日订单数、销售额

### 3.3 管理端
- 分类管理
- 商品管理（含上传主图视频）
- 用户 / 团长管理
- 全局订单
- 数据看板：销售趋势、热销 Top10、订单状态分布

## 4. 订单状态机

pending(待支付) ──支付──> paid(待发货) ──团长发货──> shipped(待自提) ──用户确认──> completed(已完成)
     │                        │
     └──取消──> canceled      └──退款──> refunding ──> refunded

规则：每次状态转换必须由后端校验「当前状态是否允许该操作」。

## 5. 视频上传需求
- L1（必做）：商品主图视频、评价视频，直传，≤50MB，mp4/webm
- L2（进阶）：分片上传 + 断点续传 + 秒传，自己实现后端

## 6. 非功能需求
- 后端所有接口返回统一格式：`{ code, message, data }`
- 错误记录日志（文件 + 控制台）
- 环境变量区分 local / production
- 部署后提供健康检查接口 `/api/health`
